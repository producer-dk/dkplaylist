# Catalog name review — 2026-10-26

Reviewed all 534 gear IDs present at the beginning of this review. 96 displayed
names changed; 515 brand metadata values were added or normalized. 526 gear IDs
had at least one change. Entry IDs, gear IDs, votes, reference links and source
broadcast payloads were preserved. No gear records were merged.

`catalog-name-review.json` records every before/after pair. The idempotent SQL
plan is generated by `scripts/review_catalog_names.py`; production before/after
values are also stored in `catalog_name_reviews`. Unchanged names were checked
for structural consistency and obvious title contamination; this is not a claim
that every model was independently authenticated against a manufacturer catalog.
